# 校准与验证记录

版本：1.0.0。日期：2026-09-09。

## 方法与范围

六类文体各两题，共十二题，另对小说、台词、界面各复写一次。题目见 [writing-cases.md](writing-cases.md)，完整输出见 [writing-outputs.md](writing-outputs.md)。

这些样稿由同一 agent 在同一对话中生成、编辑与复查，包含人工逐段反馈。未运行独立 agent、盲测或模型参数训练；部分题材与提示在校准中调整过，不属于固定的未见测试集。不使用模型自评分或 AI 检测率声称质量。

## 写作观察

| 编号 | 复查结果与调整 |
|---|---|
| A1 | 保留内部观察与新版设计的区别，没有将未外测的改动写成已获玩家认可 |
| A2 | 保留时间、地点、人数与预约条件，并保留引出活动安排的过渡 |
| P1 | 四页文案从改动到测试依据；采用视角对照与流程，制作备注与上屏内容分开 |
| P2 | 将空泛目的页与三个设问移除，合并为三页；执行名单不进入主页面 |
| S1 | 以角色与节点组织执行内容，未添加预算、录音或量化达标线 |
| S2 | 删除文档外的指导语，将事项落实到任务、角色、节点与交付内容 |
| N1 | 初稿存在主语切换、物件交接与突兀回忆；继续校准认知转折，新增期待受阻和逐步理解的铺垫。最后一段人工反馈为“好点了”，不等于完整作品已获最终质量认证 |
| N2 | 纠正动作发出者、移除无依据读心与命运升华，保留断桥和角色能力差异；仅完成本轮编辑复查 |
| D1 | 取消用卖萌收尾与工作登记式回应；保留传讯限制、关心和动作承接，没有擅自解除封印 |
| D2 | 保留{missing}与数量不足分支，移除无依据的夜间设定和敌视玩家的训斥 |
| U1 | 显示覆盖手动存档的后果，同时说明自动存档不受影响；标题、按钮在输入限制内 |
| U2 | 当前目标没有提前剧透后续交付；“读取存档”和变量进度原样保留 |

N1-R、D1-R、U1-R完成了同题复写。复写仍使用相同上下文；只能观察本轮表达变化，不能据此推断跨会话稳定性。N1-R与D1-R也按随后反馈修订了突兀转折和机械收尾。

## 技术验证

- 技能结构校验：通过。名称、描述和未完成占位检查合格。
- 界面元数据：自动调用开启，默认提示包含技能名；本地引用路径逐项检查。
- Python标准库测试：14项通过，覆盖重复编号、缺失和多余条目、正文变化、多行、空白、变量、标签、引号、反斜线及Unicode字符。
- 接入样例：独立文本稿中的8条文案写入虚构游戏资源，再从磁盘上的目标JSON读回并导出。与原稿逐条一致。
- 样例的角色绑定、数量分支、跳转和未改动内容保持不变；缺失变量与交换文本可以被检出。
- 文本核对工具不判断语言质量；角色和分支检查在样例测试中另行完成。

复现命令：

    python -m unittest discover -s tests -p "test_*.py" -v

## 调用与未覆盖项

技能描述覆盖文章、PPT、策划案、小说、台词和游戏内文案；各任务按文体读取参考，游戏写入另读接入流程。普通问答、过程汇报、纯代码逻辑和内部日志在规则中排除。

上述为静态适用性与引用检查，未进行脱离本次对话的新任务自动路由实测。未验证其他模型、真实游戏引擎、实际字幕显示或幻灯片渲染。后续在真实项目中接入时，仍需检查实际节点与画面。
