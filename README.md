# 中文写作校准 · natural-writing-zh

面向文章、PPT 文案、策划案、小说、游戏台词与游戏内文案的中文写作技能。

它按读者、用途和上下文组织内容，不采用机械禁词、固定句长、强制口语化或模型自评分。文章与工作文档默认专业而自然；小说和角色台词在没有既定作品风格时，默认偏二次元的幻想冒险表达。

## 使用

安装后可以自动匹配写作任务，也可以在请求中明确写“使用 $natural-writing-zh”。例如：

- 将这些材料整理成面向玩家的开发日志，保留必要解释。
- 为这份方案写一套汇报 PPT 文案，区分上屏文字与图形安排。
- 根据现有角色和剧情，写遗迹入口的对话；先生成独立文本稿，再接入项目。
- 修改任务提示，保持变量和实际操作一致，已经自然的文字不改。

本技能负责内容与接入前检查。真正制作幻灯片、文档或游戏时，还需要对应的制作与项目验证流程。

## 安装

从 [Releases](https://github.com/momowangOUO/natural-writing-zh/releases) 下载 natural-writing-zh-v1.0.0.zip，将其中的 natural-writing-zh 文件夹放入 Codex 用户技能目录。当前安装使用 ~/.codex/skills；采用 ~/.agents/skills 的环境可放入该目录。二者只选一个，避免重复加载。

文件夹内应直接包含 SKILL.md、agents、references、scripts 和 LICENSE。安装包不包含测试输出或本机配置。使用仓库源码安装时也只需这些文件。

如需跨任务明确调用，可将以下短段落合并到 Codex 全局 AGENTS.md，保留其他已有指令：

> 创作或改写中文文章、PPT 文案、策划案、小说、游戏台词和游戏内文案时，先读取已安装的 natural-writing-zh 技能，并只加载相关文体参考。开发任务新增或改写玩家可见文字时也适用：先独立保存纯文本、检查，再按原文接入并读回核对。已有作品与项目设定、用户当前要求优先。普通问答、过程汇报和不涉及玩家文字的代码工作不强制调用。用户只要求文案时不修改项目；已经要求实现时检查后自动接入。

不要把本机绝对路径写进分享给其他人的规则中。若本次任务未显示新技能，在新任务中检查是否能发现并读取它。

## 游戏文本接入

先读项目 → 独立纯文本稿 → 按场景检查 → 接入现有资源 → 从目标读回核对。

纯文本稿是表达依据；实现阶段只处理位置、必要转义和格式。若文本放不下，先修改文本稿，再同步到项目。

可选核对工具使用 Python 3 标准库，无额外依赖：

    python scripts/verify_game_text.py --source draft.md --actual decoded-export.json

稿件格式见 [接入参考](references/game-handoff.md)。导出文件由实际项目读取产生，只包含本批修改的编号和已解码文字。该工具不接入具体引擎，也不能验证文风、角色绑定、逻辑或画面。

## 校准与验证范围

这是指令与示例校准，不是模型参数训练。写作样例在同一对话中生成与检查，不是盲测或独立模型评审；跨任务和其他模型的稳定性尚未验证。

六类文体的题目、输出与复查说明见 [测试记录](tests/RESULTS.md)。测试中的人名、项目、情节和数值均为虚构素材。测试文件用于维护与复查，不在日常写作时默认读取。

运行工具测试：

    python -m unittest discover -s tests -p "test_*.py" -v
