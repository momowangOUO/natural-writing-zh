# 雾灯借还｜游戏内文案完整对照

[返回案例目录](../before-after.md)

## 写作任务

为雾灯借还界面编写一个完整操作流程的玩家可见文案。借灯押金为1枚银币；归还完好雾灯退还押金。界面显示持有银币 `{coins}`；借用数量固定为一盏。需要借用确认、银币不足、借用成功、物品说明、归还确认、归还成功和取消路径。损坏归还未定义，不编造处理规则。此任务只覆盖完好归还。

本次完整生成初稿后，用技能检查修改。编号和“出现条件”是制作说明，玩家文字单列。两稿使用相同编号，便于核对整条流程；没有接入真实界面。

## 初稿

### L01 · 借用确认

出现条件：玩家选择借灯，结算前。

标题：借用雾灯

正文：借用这盏雾灯需要支付1枚银币作为押金。在归还完好的雾灯后，你可以取回这枚银币。

余额：持有银币：{coins}

按钮：确认借用 / 取消

### L02 · 银币不足

出现条件：确认借用时，银币少于1枚。

标题：银币不足

正文：你目前没有足够的银币支付押金，请准备1枚银币后再来借用雾灯。

按钮：返回

### L03 · 借用成功

出现条件：扣除押金并发放雾灯后。

提示：你已成功借用雾灯，支付了1枚银币押金。

按钮：关闭

### L04 · 物品详情

名称：雾灯

说明：提在身前，可以照出雾桥的边界。归还完好的雾灯后可退回1枚银币押金。

### L05 · 归还确认

出现条件：玩家持有本次借出的完好雾灯并选择归还。

标题：归还雾灯

正文：确定要归还这盏雾灯吗？归还后将取回1枚银币押金。

按钮：确认归还 / 取消

### L06 · 归还成功

出现条件：收回雾灯并退还押金后。

提示：雾灯已归还，1枚银币押金已退回。

按钮：关闭

### L07 · 取消路径

玩家文字：无额外提示。

行为：借用或归还确认页选择取消后返回上一级，不改变银币和物品。
