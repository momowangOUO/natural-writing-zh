# 夜间还书｜小说完整对照

[返回案例目录](../before-after.md)

## 写作任务

写一个有起止的二次元幻想短场景，采用见习魔法师露弥的视角。她与学姐伊澄在图书馆关门前归还一本会自行寻找归架位置的星图册。书只能沿银色引导线移动，不能飞行；线被清洁用地毯挡住。露弥误以为书拒绝归还，随后发现原因。伊澄熟悉规则，但先观察露弥处理。最终成功还书，两人离馆。可以补充场景细节，不增加危险或反转。

两稿均为本次完整创作，初稿后依据技能作场景复查。不复原历史片段，也不冒充独立盲测。

## 初稿

### 夜间还书

图书馆的闭馆铃响过一遍，露弥才抱着星图册跑到归还台。

她将书放上银色引导线，松开手。星图册抖了抖封皮，向前滑了一小段，随即停住。露弥等了片刻，又轻轻推了它一下，书仍然没有动。

“它是不是不想回去？”她问。

伊澄站在一旁，把借阅卡收进外套口袋。

“先看看它停在哪里。”

露弥蹲下来。星图册的前沿正抵着清洁地毯，银线从地毯下面穿过去，另一端一直延伸到书架。她这才想起，书册只能沿着银线移动。

“原来是挡住了。”

她掀起地毯，星图册便继续向前滑去。露弥跟着走了几步，看着它绕过书架，在最下面一层空位里停稳。

“还好没有推坏。”她松了口气。

“下次不用推。”伊澄说，“它知道自己该去哪一格。”

露弥把地毯折到银线旁边，确认不会再挡住其他书，才回到归还台。卡片上的借阅记录已经消失了。

第二遍闭馆铃响起，两人一起走向门口。露弥回头看了一眼，星图册已经安静地待在架上，看不出刚才让她着急的样子。

## 修改稿

### 夜间还书

图书馆响起第一遍闭馆铃时，露弥刚跑上最后一级台阶。她抱着星图册挤进门，袖口被铜把手勾住，又退回去解。

伊澄替她扶住门。

“来得及，先把气喘匀。”

归还台上只剩一条银线还亮着。露弥将星图册放上去，书脊朝外，照着借书时的样子摆好。厚厚的封皮抖了一下，书便贴着台面滑下斜坡。

露弥刚要去拿借阅卡，书又停了。

她等了等，伸出一根手指，抵住书脊往前送。封皮擦过地毯的毛边，发出很轻的一声响。

“它是不是不想回去？”

“你先别推。”伊澄俯身看向台下，“刚才碰到什么了？”

露弥蹲下去，才发现斜坡底下铺着清洁用的地毯。书的前沿陷在毛边里，银线到了这里也断了。她掀开一角，底下立刻透出细细的光。

星图册往前挪了一寸。

露弥忙把手抬高。书跟着露出来的银线滑过去，绕过她的鞋尖，停在下一块被遮住的地方。

“啊……你是过不去。”

她将地毯折到一旁，给整条线让出位置。星图册这次没有停，一路滑进书架最下面的空格。封皮合拢时，归还台上的借阅卡亮了一下。

露弥抽出卡，确认书名从上面消失，才收进口袋。

“刚才还以为要把它抱回去了。”

“明天就逾期了。”

“所以才赶着来嘛。”

第二遍铃响了。露弥走到门边，这回先把袖口拢好，伸手替伊澄扶住门。

## 编辑记录

初稿的情节完整，但发现地毯后直接回忆规则，解决问题过快；末段还重复交代了已经完成的还书结果。修改稿用书随银线露出而移动的现场反馈，让露弥逐步发现原因。新增借阅卡和门把手细节用于确认归还、收束人物互动，均属于任务允许的虚构补充。

书始终贴着银线移动，没有获得飞行能力；视角没有进入伊澄的内心。改稿较长，用篇幅换取现场过程，不把“变长”本身当成改善。
